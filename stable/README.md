# Stable

Dieser Bereich ist fail-closed. Zulässig sind nur Artefakte mit vollständiger Promotion-Evidenz für alle Stufen und Samuels explizitem Owner Gate.

Ein Registry-Eintrag, eine Installation oder ein erfolgreicher Einzeltest reicht nicht. Ohne Promotion-Record bleibt das Artefakt in `workbench/` oder `parking/`.
