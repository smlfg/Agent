# Workbench

Hier dürfen freie, reversible Versuche entstehen. Alles in diesem Bereich ist unqualifiziert, darf keine Stable- oder Capability-Behauptung tragen und bleibt innerhalb eines Run-Contracts.

Ein Versuch wechselt nur über den vollständigen Promotion-Vertrag in `stable/`. Scope- oder Drift-Funde werden als eigener Slice verzweigt oder in `parking/` abgelegt.
