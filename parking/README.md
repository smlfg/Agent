# Parking

Parking nimmt unbegrenzt Ideen, Drift-Branches und unterbrochene Slices auf, ohne sie als aktiv oder erledigt auszugeben. Jeder Eintrag braucht einen Resume-Punkt, bekannte Pfade und genau einen nächsten Schritt.

Die operative Wahrheit über höchstens zwei aktive Top-Level-Lanes bleibt `~/Control/ACTIVE_PROJECTS.md`; der Tagesstand bleibt `~/Projects/00_AKTUELL/JETZT.md`.
