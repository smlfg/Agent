Der HAI Harness Check wandelt ein unbestimmtes Agentenproblem in einen begrenzten nächsten Schritt um. Die Person wählt Harness, Erfahrungsstufe und Problem und erhält ein begrenztes Onboarding-Profil. Vorgesehen sind keine Secrets, keine Uploads, kein Repository-Zugriff und eine menschliche Entscheidung. Eine Session kann mit einem Paket abgeschlossen werden, das nur in der Browser-Sitzung bleibt. Zum beschriebenen Zeitpunkt war der Live-Chat vorübergehend deaktiviert und leitete Eingaben nicht an ein KI-Modell weiter.
