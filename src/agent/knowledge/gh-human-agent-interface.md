Human Agent Interface ist eine öffentliche Website und ein Frontend für einen Kontrollansatz bei agentischer Arbeit. Menschliche Absicht soll vor der Ausführung sichtbar, prüfbar und wiederherstellbar bleiben. Der beschriebene Ablauf verbindet Absicht, Kontext, Routing, Gedächtnis, abgegrenzte Agentenarbeit, Verifikation, Übergabe und eine Eigentümerentscheidung. Das Repository enthält die statische JavaScript-Website hinter der öffentlichen Präsenz. Verwandte Komponenten sind eine MCP-Kontrollschicht und ein Profil mit Bauprinzipien. Das Projekt steht unter MIT-Lizenz.
