wifionice ist eine CLI für das WIFIonICE-Zug-WLAN. Sie prüft das Captive Portal, führt den Portal-Check-in mit AGB-Bestätigung aus, zeigt Session-Status und Zuggeschwindigkeit und unterstützt den lokalen Logout. Für Check-ins gelten interaktive Bestätigungen oder explizite Flags für nicht-interaktive Nutzung. Die CLI benötigt und speichert keine Zugangsdaten. Sie bietet JSON-Ausgabe, Dry-Run, Konfiguration über Umgebungsvariablen oder Datei sowie definierte Exit-Codes. Tests laufen offline mit einem Fake-Server. Das Werkzeug ist nicht offiziell und wird auf eigene Verantwortung genutzt.
