samuelfleig.com ist eine persönliche Dachseite mit drei Bereichen für Arbeit, Lernen und Leben. Die Seite besteht aus semantischem HTML, eigenem CSS und Vanilla-JavaScript mit ARIA-Unterstützung. Selbst gehostete Schriften ermöglichen Offline-Betrieb ohne externe Requests. Lokal lässt sich die Seite über einen Python-HTTP-Server ansehen. Das Deployment erfolgt als Cloudflare Worker mit Static Assets und den Dateien index.html, style.css, script.js sowie fonts/. Der Quellcode steht unter Vorbehalt; die Schriften sind unter der SIL Open Font License lizenziert. Die Live-Adresse lautet https://samuelfleig.com.
