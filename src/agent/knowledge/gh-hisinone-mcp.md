hisinone-mcp ist ein ausschließlich lesender MCP-Server für HISinOne-Campusportale. Er ermöglicht die öffentliche Suche nach Veranstaltungen und das Lesen von Veranstaltungsdetails. Nach einer Anmeldung können persönliche Stundenpläne und Leistungsübersichten abgerufen werden. Der Server nutzt Kernfunktionen von hisinone-cli und bietet strukturierte Daten sowie lesbaren Text. Passwörter werden nicht als Tool-Argumente verarbeitet; Sitzungen liegen lokal. Die Hochschulbasis-URL ist konfigurierbar. Es gibt keine Aktionen für Belegung oder Prüfungsanmeldung. Portaländerungen können die Auswertung beeinträchtigen. Das Projekt steht unter MIT-Lizenz.
