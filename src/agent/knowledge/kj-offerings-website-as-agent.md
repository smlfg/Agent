Eine Website kann selbst der Agent sein und nicht nur eine Seite mit danebenstehendem Chat. Sie richtet sich an Studios und kleine Teams, die eine Website wollen, die Antworten gibt statt nur zu informieren. In einem Beispiel fragt ein Studioinhaber nach Möglichkeiten; die Oberfläche antwortet in wenigen kurzen Zeilen und stellt eine konkrete Rückfrage.
