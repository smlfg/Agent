HAI-MCP ist eine modellagnostische MCP-Steuerungsebene für eine Human-Agent-Interface-Arbeitsweise. Sie begrenzt, autorisiert und protokolliert agentische Arbeit, ohne selbst ein LLM aufzurufen, Shell-Befehle auszuführen, Git zu pushen oder Dateien zu löschen. Funktionen umfassen Missionsverträge, Sitzungsleases, Aktivitäts- und Driftprüfung, Fokus und Lanes, Owner-Gates, Belege, Abschluss, Checkpoints und Wiederherstellung. Der Server unterstützt stdio sowie streamable HTTP mit optionaler Tokenbindung. Eingaben werden strikt typisiert und bei Fehlern geschlossen abgewiesen.
