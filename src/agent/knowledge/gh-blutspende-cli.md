blutspende-cli findet Blutspendetermine im Terminal. Es unterstützt Suche nach Postleitzahl, Ort oder Landkreis, Umkreis- und Zeitraumfilter, Details, den nächsten Termin, lokale Watches und das Speichern von Kalendereinträgen. Das Werkzeug benötigt keinen Login und führt keine schreibenden Aktionen aus. JSON wird bei nicht interaktivem stdout standardmäßig ausgegeben. Standardort, Watch-Zustand und Cache werden lokal gespeichert. Reservierungen erfolgen ausschließlich über einen angezeigten Link. Die Anwendung nutzt öffentlich erreichbare Such-, Detail- und Kalenderseiten sowie RSS-Daten; eine offizielle API ist nicht genannt. Zugriffe werden auf höchstens eine Anfrage pro Sekunde begrenzt. Änderungen an der Website können das Werkzeug beeinträchtigen.
