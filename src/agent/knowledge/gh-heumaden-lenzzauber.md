Heumaden Lenzzauber ist eine kleine mobile Festival-Website für eine private Abschiedsfeier. Das digitale Ritualportal verbindet Lore, Stimmung und praktische Orientierung. Die One-Page-Oberfläche bietet einen Tab-Switcher für das Line-up, eine Timeline, Informationskarten, eine Kartenverlinkung und einen angekündigten Zahlungslink. Die Website verwendet Plain HTML, CSS und JavaScript ohne Framework und wird über GitHub Pages gehostet. Die Projektstruktur enthält eine HTML-Datei, Stylesheets, JavaScript-Dateien, Assets sowie Plan- und README-Dokumentation.
