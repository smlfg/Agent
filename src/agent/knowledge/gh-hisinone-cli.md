hisinone-cli ist ein Terminalwerkzeug für HISinOne-Campusportale. Es durchsucht öffentliche Vorlesungsverzeichnisse und zeigt Veranstaltungsdetails. Mit Login stellt es außerdem Stundenpläne und Leistungsübersichten bereit. Sitzungen werden lokal mit eingeschränkten Dateirechten gespeichert; Passwörter werden nicht gespeichert. Die Ausgabe erfolgt im Terminal oder als einzelnes JSON-Objekt. Das Werkzeug verwendet keine offizielle API und führt bewusst keine schreibenden Hochschulaktionen wie Prüfungsanmeldung oder Belegung aus. Über eine Umgebungsvariable kann eine andere HISinOne-Instanz angesprochen werden.
