HAI-MCP ist eine MCP-Steuerungsebene für begrenzte agentische Arbeit. Sie bindet Agentenarbeit an Missionsverträge, Owner-Gates, Drift-Prüfungen und evidenzbasierte Fertigstellung. Das System ruft selbst kein Sprachmodell auf; das Modell bleibt im Client. Gesteuert werden Missionsverträge, menschliche Freigaben, Abweichungsprüfungen, überprüfbare Abschlusskriterien und nächste Schritte über Sitzungen hinweg. HAI-MCP wird als Python-MCP-Server und als Umsetzung der HAI-Methode beschrieben.
