Human Agent Interface ordnet agentische Arbeit so, dass Menschen sie beobachten, begrenzen, prüfen und verantworten können. Es richtet sich an Personen mit chaotischen Agenten-Workflows und führt von einem konkreten Problem zu einem prüfbaren nächsten Aktionspaket. Der Ansatz beschreibt menschliche Kontrolle über Handlungen, Freigaben und Verifikation. Er umfasst außerdem einen interaktiven Beispielablauf, eine Definition, Angebote, Fit-Prüfung und Nachweise aus lokalen Agentensystemen.
