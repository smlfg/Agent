Das Harness-Tutorial beschreibt eine Entscheidungskette für den kontrollierten Einsatz von Coding-Agenten. Sie umfasst Owner-Paket, Scope-Grenze, Delegationskarte, Verifier-Schleife und nächste Aktion. Für jedes Tool werden Rolle, erwartetes Artefakt und menschlicher Stopppunkt festgelegt. Der Ablauf besteht aus Intake, einem kurzen Plan, begrenztem Build, Evidenz, Review und Übergabe. Erfolg wird durch Tests, Smoke-Checks, Dokumentstruktur, Screenshots oder Diffs belegt. Der Mensch entscheidet über neue Abhängigkeiten, destruktive Aktionen, Geheimnisse, Authentifizierung, Deployment, Scope-Ausweitung und unklare Tests. Markdown-Artefakte bleiben die Wahrheitsebene. Das Tutorial behandelt mehrere Agentenoberflächen und verweist auf Referenzen, Vorlagen und Praxisabläufe.
