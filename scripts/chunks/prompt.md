Erstelle je Quelle genau einen Wissens-Chunk. Halte Quellen strikt getrennt.
Übernimm nichts aus anderen Quellen. Schreibe auf Deutsch, dritte Person,
sachlich, ohne Superlative, maximal 120 Wörter. Keine Namen Dritter und keine
Kontaktdaten. Der Navigationslink wird deterministisch aus den Quell-Metadaten
übernommen (`link` im JSON kann null sein oder die Quell-URL spiegeln).
`aliases` sind Namen/Begriffe, unter denen man danach fragen würde. `waypoints`
enthält Werte aus `what-this-is`, `creator`, `product-for-x`, `*`.
